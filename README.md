## 💡 TaskBridge とは？

**「全体のスケジュール（WBS）と、現場の今週のタスクが繋がらない」**
**「指示外で突発的に発生した仕事がチャットで流れ、実績工数として集計されない」**
というプロジェクト管理の課題を解決するための、現場ファーストな進捗管理ツールです。

### 🌟 特徴
1. **メンバー視点のホーム画面（最優先ビュー）**:
   - ログイン・開いた瞬間に「今週のあなたの作業指示」を一覧表示。
   - 迷わず今日の報告・進捗入力が完了します。
2. **指示外作業の既存WBS紐付け集計**:
   - 現場で起きた予定外の作業（緊急調査、仕様変更、突発MTGなど）を「指示外作業」として登録。
   - 既存WBSの該当工程・機能に紐付けるため、担当者別の集計時に実績として確実に計上されます。
3. **週次作業指示の自動作成**:
   - 前週の未完了タスクとWBSのスケジュール予定から、翌週の作業指示ドラフトをワンクリックで自動抽出・生成。
   - 管理者の指示作成の手間を大幅に削減します。
4. **ゼロインストール・即時動作**:
   - Node.js等の環境設定は一切不要。Windows標準機能だけで起動・利用できます。

## 🚀 起動方法

### 方法1: バッチファイルから起動（一番簡単）
プロジェクトフォルダ内の `run_app.bat` をダブルクリックするだけです。
ローカルWebサーバーが立ち上がり、自動的にブラウザでTaskBridgeが開きます。

### 方法2: PowerShellスクリプトから起動
PowerShellコンソールで以下を実行します：
```powershell
cd c:\Users\BS227\Documents\antigravity\TaskBridge
.\start_app.ps1
```

### 方法3: ブラウザで直接開く
`index.html` をブラウザ（Google Chrome, Edgeなど）にドラッグ＆ドロップして開くことでも、すべての機能をそのままご利用いただけます。

## 📋 主な画面と操作ガイド

- **【ホーム】今週の作業指示・進捗報告 (メンバー向け)**
  - 画面上部のメンバーセレクターで自分の名前を選択。
  - 今週割り振られたタスクの「進捗率」「実績工数」「報告メモ」を入力して保存。
  - 「＋指示外作業の追加」ボタンから、予定外の作業を登録。既存WBSの工程を選んで紐付けます。

- **【週次指示】作業指示の自動生成・配付 (管理者向け)**
  - 「来週の指示を自動生成」ボタンをクリック。
  - 前週の残り作業とWBS予定から、各メンバーの指示候補が自動生成されます。
  - 内容を確認・調整して「メンバーへ指示を配付」をクリックすると、メンバーのホーム画面に反映されます。

- **【WBS】プロジェクト全体スケジュール (管理者/メンバー)**
  - 工程（フェーズ）→機能→タスクのツリー構造を表示。
  - 予定工数と、メンバーが報告した指示内＋指示外の合算実績工数をリアルタイム比較。

- **【実績集計】工数・分析ダッシュボード**
  - メンバーごとの「指示内工数」「指示外工数」の内訳グラフと合計を表示。
  - 指示外作業の一覧ログと発生理由を分析できます。
